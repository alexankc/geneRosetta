# Compress a File Using Streaming Gzip

Compress a File Using Streaming Gzip

## Usage

``` r
.compress_gz(src_file, gz_file, level = 9)
```

## Arguments

- src_file:

  Path to source uncompressed file.

- gz_file:

  Path to destination .gz file.

- level:

  Gzip compression level (1-9). Defaults to 9.

## Value

The destination path, invisibly.
