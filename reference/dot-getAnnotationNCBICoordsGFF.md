# Get NCBI Genomic Coordinates from GFF3

Get NCBI Genomic Coordinates from GFF3

## Usage

``` r
.getAnnotationNCBICoordsGFF(
  species,
  annotation_dir,
  force_update = FALSE,
  offline = getOption("geneRosetta.offline", FALSE)
)
```

## Arguments

- species:

  Species name.

- annotation_dir:

  Directory path.

- force_update:

  Logical.

- offline:

  Logical.
