# NCBI GenBank Assembly Locations

The GenBank accession prefix directory for each species on the NCBI
genomes FTP site, plus a pinned assembly directory used when the live
listing cannot be read (offline, or Ensembl has moved to a build NCBI
has not published yet).

## Usage

``` r
.ASSEMBLY_SPECIES
```

## Format

An object of class `list` of length 3.
